第二章 Still Here

电话那头安静了很久。

他握着手机，没说话。窗外香港的夜还在流动，楼下有人用粤语喊孩子回家，电车叮叮当当地过去。窗帘透进来的光很薄，把房间照成深深浅浅的灰。他听见自己的呼吸，听见电话那头也有人在呼吸。

“Lou。”

他愣了一下。

——这个声音他多久没听到了。

“Austin。”

“嗯。”

“……你怎么——”

“我想起你，”Austin说：“想起来就打了。”

他握着手机，没有说话。他不知道该怎么接这句话。在香港这么久，他听惯了粤语的尾音，听惯了Stephen平稳的声线，听惯了Simon嘻嘻哈哈的笑。他很久没听过这种声音——这种从太平洋那一头、隔着整片大陆、隔着十年的距离，还像坐在他旁边一样的声音。

“你呢，”Austin说：“你还好吗？”

“还好。”

“真的？”

他笑了一下。那个笑没有声音。

“你怎么——”

“我听得出来，”Austin说：“你说‘还好’的时候，停顿太长。”

他握着手机，沉默了一会儿。

窗外的电车又过去了。

“你小时候就这样，”Austin说：“你说‘没事’，就是有事。你说‘我很好’，就是不太好。你从来都这样。”

他低下头，看着自己的手。手指上的茧还在。弹吉他的茧，握笔的茧，分不太清。

“你还记得吗，”Austin说：“你那时候——”

他点头，没让 Austin 说完。

“记得。”

——太记得了。

那一年，他还小。或者说，他来香港几年了。他已经会说“放咗学”，会在陈雅雯生日的时候用广东话唱生日歌，会跟邻居阿姨开玩笑。他把林家当成自己的家，把这条街当成自己的街。学校里没有人觉得这个少年有什么特别——除了他眼睛的颜色。那是很难藏起来的颜色，所以他总是习惯性地低下头，让刘海挡住一点。

可他有一个地方，是谁都看不见的。

放学后，大家都走了。他一个人，走进旧教学楼三楼尽头的音乐室。窗户对着操场，傍晚的光把一架旧钢琴染成金黄色。他不弹钢琴。他从书包里掏出一把旧的木吉他——琴身上有一道裂纹，他用透明胶粘住，声音有一点闷，但他不在乎。

他坐在窗台上，抱着吉他，练习。

他以为没有人在听。

——可有人推开了门。

那是谁？

——他现在说不上名字了。只记得那是个男生，背着书包，站在门口，看了他一眼。然后那个人走进来，坐到前排的第一把椅子上，隔着一排座位，看着他。

“继续啊。”

他停下。

“我练得不好。”

“没关系的，”那个人说：“你练你的。我在这坐会儿。”

他不知道那个人是谁。可那个下午的光，是金色的。从窗户打进来，落在那个人脸上，落在旧钢琴上，落在他手指按着的琴弦上。他抱着那把有裂纹的吉他，弹了一首自己写的歌——副歌是现写的，主歌是以前攒下的，唱的时候他自己都不太确定，调对不对。

他唱完了。

那个人说：“你弹得很好听。”

——他后来跟这个人做了朋友。再后来，他发现自己喜欢这个人。再后来，他把这个秘密全交了出去。

那些，都是后来的事了。

他当时只是抬起头，看了那个人一眼。窗外的光很亮，他眯着眼睛。

——他叫什么来着？

Austin。

对，Austin。

他记得了。

他记得那个下午的光很亮，Austin 站在门口，校服外套搭在肩上，书包的带子歪了一根。他记得 Austin 的眼睛是棕色的，笑起来的时候会弯起来。他记得 Austin 说“继续啊”的时候，语气不像陌生人的鼓励，倒像是他们认识很久了。

那以后，他们变成了朋友。

放学以后，他们会绕远路走。从学校后门出去，穿过菜市场，再沿着海边那条路，走回公屋。菜市场傍晚很挤，卖鱼的阿婆用粤语喊价，烧腊店飘出蜜糖的味道。Austin 会买两罐汽水，他们边走边喝，聊音乐。Austin 说他喜欢听英文歌，林森浩说他写的东西都藏在笔记本里。Austin 说：“那拿出来听听。”林森浩说，还没写完。Austin 说：“没写完也行。”林森浩想了想，把书包里的笔记本掏出来，翻到最新那一页，递给 Austin。Austin 就着路灯的光看了一会儿，然后抬头说：“这句词改成‘under the same sky’会更好。”林森浩愣了一下，低头看那行字——他本来写的是“under the sky”。他想了想，把那句改了过来。那是他们第一次一起改词。

不是那种客客气气的同学。是那种不用说话也知道对方在想什么的朋友。放学一起走。周末一起去海边。Austin 听他弹琴，听他唱歌，听他说那些从来不敢跟别人说的话。

那时候他写了一首还没写完的歌。

他记得的是这些——

不是逐字逐句的词。是片段。是感觉。

他记得窗外下着雨，雨声在音乐室的屋檐上敲得很密。他记得 Austin 坐在钢琴凳上，一只手撑着下巴，眼睛看着窗外的雨。他记得他写了几个和弦，反反复复地弹，又反反复覆地改。他记得 Austin 偶尔哼一句，他偶尔哼一句，哼到后来，两人的声音叠在一起。

——词是从哪里开始的？

他不记得了。

只记得几个词，断断续续，像从很远的地方飘过来。

Still here, still here, under the same sky…

——那个 sky，Austin 拖得很长。长到他以为 Austin 不会停了。可后来 Austin 停了。他说，这一句留着。其他的，我回去再想。

其他的，他们后来也写了。

可他现在不记得完整的样子了。

他只记得，写完那天，雨停了。音乐室的窗上有一层薄薄的雾气。他看着窗外亮起来的一片一片的灯，问 Austin：

“我们给它起个名字吧。”

Austin 想了想。

“就叫《Still Here》。”

——Still Here。

他念了一遍。又念了一遍。

Still Here. Still Here.

“什么意思？”

“就是字面意思，”Austin说：“我们还在这里。我们都还在。”

他看着 Austin 笑。他也笑了。那是一种他自己都没见过的笑——在别人面前不会有的笑。

那是他第一次感觉到，写一首歌，原来是这样的。

后来的日子，他们是这么过的。

放学一起走。海边一起坐。Austin 听他弹琴，听他唱歌，听他说那些从来不敢跟别人说的话。

他说他想写歌。Austin 说我听。他说没人会听他的歌。Austin 说你写了我听。

那段时间他们几乎每个周末都泡在音乐室里。Austin 带了一本空白的笔记本，他带了一把吉他。窗外的雨下了很久，他们在教室里改词改到天黑。Austin 会先把词写在草稿纸上，用铅笔涂掉再写，林森浩就坐在旁边弹和弦，弹几句停下来，改一个音，再弹几句。Austin 偶尔会哼一段旋律，林森浩就跟着弹，两个人哼着弹着，有时候会卡在一个地方，谁也不说话。林森浩就盯着琴弦，Austin 就盯着天花板。然后 Austin 想了想说：“这里换成大三和弦试试？”林森浩弹了一遍，变了，不一样了。他说，对，就这个。Austin 就低头在笔记本上写下来。写完之后，Austin 会把写好的部分读一遍，林森浩会再弹一遍。读着弹着，副歌就慢慢长出来了。

——那一年，他写了什么，他不记得了。

可他记得 Austin 说过的一句话。

那天傍晚，他们又坐在海边。他抱着吉他，唱了一首自己写的歌。唱到一半，他泄了气。

“很烂吧。”

Austin 没说话。过了一会儿，他说：

“你为什么要写歌？”

“……不知道。就是想写。”

“那就是了。” Austin 说：“你不是为了让别人听才写的。你是为了自己。”

他低着头。

“可是没人听的话，写了有什么用。”

Austin 看着他。很认真地说：

“你不能因为没人听，就假装自己没有声音。”

他抬起头，看着 Austin。窗外的光落进来，把 Austin 的眼睛照得很亮。

——他没有告诉 Austin，那句话，他记了很多年。

后来 Austin 又说了一句。那句话，他记了更久。

“因为我们听过。”

——这一句。

他记得很清楚。

不是因为这句话预示了什么。不是因为后来真的有人听他的歌。

是因为——在他什么都没有、还只是一个香港公屋学生的年纪——有一个人，认真地、安静地、把他弹的每一个音都听完了。

那是他后来所有音乐理念的起点。

——在那个起点上，有人对他说：因为我们听过。

那一年，他们给那首歌起了名字。

名字写在笔记本最上面。Austin 的字迹。

Still Here.

下面，是两个并排的名字。

林森浩

Austin

——那本笔记本，他后来带在身边很多年。从香港带到美国，从美国带回香港。从录音室带回家，从家带回录音室。从第一张专辑带到第二张。从那时带到后来。

笔记本的封面磨破了。封底的折角翘起来。他用透明胶粘了又粘，胶痕一道一道。

——可名字还在那里。

后来，他们越来越亲密。

从朋友，到知己，到恋人。

没有谁先告白。只是有一天傍晚，他们又坐在海边。林森浩弹吉他。Austin 靠在他肩上。

——他记得海风。他记得海风把 Austin 的头发吹到他脖子上的那种痒。他记得他没有躲。

——他记得 Austin 看着远处说了一句什么，他没有听清。他只记得，他把那段副歌又弹了一遍。这一遍，弹得很慢，很轻。

——那是他们在一起的那个傍晚。

那天傍晚的海风是咸的，带着沙子和水草的气味。远处的海平线有一艘船，亮着灯，慢慢地移动。林森浩弹完那遍副歌之后，没有抬头。他能感觉到 Austin 靠在他肩上的重量，能感觉到风从他们的腿间穿过去。他就那么坐着，把吉他放在腿上，手指放在琴弦上，没有弹。海浪声一下一下地打过来，节奏跟他的心跳差不多。

——他后来记了很久。

——他后来在那首歌的某一个版本里，把那天的海风偷偷录进去了一点点。

那是林森浩人生中第一次觉得，自己可以完整地被喜欢。

不需要藏起任何一部分的自己。

——所以后来，当他想把那个秘密说出口的时候，他没有犹豫很久。

那天傍晚，他们还是坐在海边。林森浩抱着吉他，很久没有说话。Austin 没有催他。只是坐在旁边。等。

“我有件事，从来没告诉过你。”

Austin 嗯了一声。

——他说了什么？

——他不记得了。

他只记得自己心跳很快。他只记得自己眼睛看着自己的手指，看着琴弦上反射过来的光。他只记得他说出那句“我其实不叫林森浩”的时候，自己的声音抖了一下。

然后——很长的安静。

——他不敢抬头看 Austin。

——他怕 Austin 的眼神会变。变成那种知道了 Tomlinson 家族之后，小心翼翼或者另眼相看的眼神。

——他怕了很多东西。他怕失去 Austin。他怕失去自己好不容易才有的“完整”。他怕从此以后，Austin 再也不叫他 Lou，而叫他“Tomlinson 家的人”。

他低着头，看着自己的手。

——然后 Austin 说话了。

“……所以，‘林森浩’不是你的真名？”

——林森浩。

林森浩是他爸爸取的。林志明。是他小时候被送到香港之前，那个男人蹲下来，看着他的眼睛，对他说：“你叫林森浩。你永远叫林森浩。”

——这件事，他一直记着。

“是真名，”他说：“是我爸取的。林志明。他给我取的。”

“那就是你的名字。” Austin 说：“名字是谁取的，有什么关系。”

——那句话。

——他在那个傍晚，听到了那句话。

——后来很多年，他都没忘记。

——后来他上台唱歌的时候，他以为没有人知道他的真名。后来他在节目里说自己是“那个写歌的小孩”。后来他在采访里被问“你是谁”。后来他在红毯上被问“你从哪里来”。

——他每次想起的，都是这一句。

——名字是谁取的，有什么关系。

那是他第一次，把完整的自己交给另一个人。

——他后来想了很久，为什么 Austin 能这样。知道了他的全名、他的家族、他的来历，依然这样平静地坐在他身边。

——他想了很久，答案其实很简单。

Austin 喜欢的一直是那个在海边弹吉他的林森浩。至于他姓什么，从来不是 Austin 在乎的事。

——后来他们还是朋友。

——后来他们还是恋人。

——后来他们一起写了很多歌。Austin 写词，他写旋律。Austin 哼一句，他弹一遍。Austin 改一个词，他就跟着改一个和弦。

——那些歌里，有没有后来的那首“关于墙”的歌呢？

——他不记得了。

——他只记得那时候的海风，那时候的光，那时候 Austin 哼副歌时长长的尾音。

——他只记得那时候，他以为这样的日子会一直一直下去。

后来 Austin 走了。

——爸爸的工作变动，美国那边的高中给了他一个名额。是很好的机会。好到没有人有理由让他留下来。

——那天他们在海边坐到很晚。

——Austin 说：“你会不会觉得我很自私？”

他说：“不会。这是你的路。”

——Austin 说：“可是我不想走。”

——他没有说话。

——走之前那天傍晚，他们最后一次去了海边。

Austin 说：“我们唱一次那首歌吧。”

他们唱了。

——他唱到一半，Austin 的声音抖了一下。

——他没有问为什么。

——唱完之后，很久都没有人说话。

那天傍晚比平时更凉。风从海面上吹过来，把 Austin 的头发吹乱了。他没有伸手去理。他坐在林森浩旁边，两个人之间隔着那把吉他。林森浩弹了那首歌的前奏，弹了三遍，没有进主歌。Austin 跟着哼了几句，声音很轻，轻得像怕打扰什么。林森浩停下，看了他一眼。Austin 也在看他。两个人对视了一会儿，谁都没有说话。

然后 Austin 说：“林森浩。”

他说：“你说。”

“不管你在香港，还是以后去了别的地方，” Austin 看着他，一字一句地说：

“不要为了适应这里，忘记你是谁。”

——他眼睛一热。

——他从来没有把这些话说出口过。可 Austin 替他说了。

——他从来没有告诉 Austin，他其实一直不知道自己是谁。Tomlinson 家的人？香港的学生？写歌的小孩？哪一个才是他？他不知道。他只知道，他把那些问题藏得很深，深到连他自己都不太敢去看。

——Austin 一句话，把那些东西全翻了出来。

“答应我。” Austin 说。

“……好。”他说。

——那是 Austin 离开之前，他们最后一次认认真真地看着对方的眼睛。

——后来 Austin 就走了。

——没有狗血。没有争吵。没有背叛。

——只是两个少年，第一次发现，喜欢一个人，不代表一定能留住一个人。

——他后来想，他们都没有变心。他们只是被人生，推向了不同的方向。

挂断电话之后，房间里安静了很久。

楼下有人关了灯，电车叮叮当当地过去，又远去。

林森浩坐在床边，手里握着手机，屏幕已经暗下去了。他看着窗玻璃上映出的自己的脸。那时，头发有点乱，眼睛里有一点他自己都不太认得的东西。

他坐了一会儿，然后站起来，走到书桌前，拉开抽屉。

抽屉最里面，压着那本旧琴谱本。他把它拿出来，指尖拂过封面。封面上贴着的那些便利贴还在——Simon 借伞，Stephen 递提纲，林妈妈晾衣服。他一张一张看过去。

他翻开第一页。

第一页不是空白的。

那是很久以前写的，墨迹已经有些旧了。

Still Here.

——那个名字。

——他念出声来。Still Here. Still Here.

下面，是两个并排的名字。

林森浩

Austin

他看着那两个名字，看了很久。

——那时的下午，金色的光，琴弦上的裂纹，雨声。

——两个少年趴在桌上写歌的样子。

——Austin 拖得很长的那个 sky。

——他念出声来。“Still here, still here, under the same sky.”

——他忽然想，他也许真的该去美国。去看看 Austin。去听听 Austin 现在的歌。去站在他面前，让 Austin 再听一遍，他现在的歌。

——也许 Austin 听了会说什么。

——也许 Austin 只是笑一下，像以前一样。

——可他想去。

他把琴谱本合上，抱在怀里。

窗外的香港还在流动。楼下有人在唱歌，唱的是他听不懂的粤语歌。他坐在窗边，听着那首歌，心里冒出一个念头——

他这一生，到目前为止，写得最好的一首歌，是少年时代在雨天的音乐室里，和一个人一起写的。

那个人的名字，他写在了琴谱本上。

那个人的声音，他记到了现在。

——Still Here.

——他们都还在。

他翻了个身，看着天花板。手机里那条“欢迎回家”的消息还亮着。他想，他大概，要回美国一趟了。

不是因为别的原因。

只是因为，那首歌，是两个人一起写的。一个人唱，不算完整的。

——他还欠那个人，一次重新唱一遍。

窗外的夜很深。他闭上眼睛。他不知道他会不会做出那个决定。可他知道——

他心里那个叫“Lou”的自己，已经醒了。

他不能再把它，按回梦里去了。

他低头看琴谱本里夹着的那张纸，是 Austin 当年写词的那张草稿纸。铅笔写的，有些字被涂掉了，有些地方画着小圆圈。最下面有一行字，Austin 的笔迹，很小：“我们都在，不管多远。” 他看了很久，然后把那张纸折好，夹回原处。

——第二章 完——
